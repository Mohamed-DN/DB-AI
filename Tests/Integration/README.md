# Integration Tests

## Scopo del progetto
End to end validation scripts for the v3 stack.

## Installazione e Setup
Start docker-lab and the backend before running tests.

## Architettura
Scripts orchestrate container lifecycle, run Scout, simulate failures,
run CriticalAlert, and validate outputs.

## Utilizzo
PowerShell:
.un_advanced_scenario.ps1
Check console output and the emails/ folder.
