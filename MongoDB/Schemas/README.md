# MongoDB Schemas

## Scopo del progetto
Define expected document shapes and conventions for CMDB collections.

## Installazione e Setup
No direct setup. Follow MongoDB/README.md.

## Architettura
- identity section for db identity and topology
- connection section for host, port, credentials
- configuration section for engine specific settings
- state section for runtime status and metrics
- metadata for timestamps and audit fields

## Utilizzo
Use these schemas when adding new collectors or API endpoints.
