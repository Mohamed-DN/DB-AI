# Collection: monitoring_alerts

## Scopo del progetto
Stores alerts generated by agents and external monitoring.

## Installazione e Setup
Created by CriticalAlert and CheckMK Bridge.

## Architettura
Common fields: state, severity, database, host_name, service, output, processed, timestamp.

## Utilizzo
db.monitoring_alerts.find({ state: "CRITICAL", processed: false })
db.monitoring_alerts.updateMany({ processed: false }, { $set: { processed: true } })
